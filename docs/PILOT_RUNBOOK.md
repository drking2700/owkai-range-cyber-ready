# Pilot Runbook

## Before cohort
1. Run `pytest` and `python scripts/secret_scan.py .`.
2. Initialize DB and learner IDs.
3. Confirm AI provider mode and daily budget.
4. Confirm consent language and retention terms if using an external provider.
5. Run one technical and one nontechnical dry run of Missions 1, 5, and 9.

## Weekly learner flow
1. Complete prerequisite learning.
2. Read one-page mission brief.
3. Bootstrap local mission workspace.
4. Use bounded AI assistance as needed.
5. Make changes and preserve evidence.
6. Complete `ai_work_record.json`.
7. Run deterministic verifier.
8. Submit work via PR in learner-owned repository.
9. Complete AAR.
10. Attend cohort call.

## Human checkpoints
Missions 8, 12, and 16 require human approval.

## Pilot measures
Completion, time per mission, hint use, verification failures, AAR trajectory, AI rejection/correction quality, cost per learner, support burden, and cold explanation quality.
